# GuildMaster

![GuildMaster](../assets/guildmaster-logo.png)

**GuildMaster 1.0.0** — самостоятельный плагин гильдий для Bukkit-серверов от **VaelisWorld**. Он объединяет управление гильдиями, ранги, отношения между гильдиями, дома, чат, территории, рейтинги и постоянное хранение данных в SQLite.

> **Язык:** English / Русский  
> **Платформы:** Paper, Purpur и Spigot  
> **Основная совместимость, проверенная в тестовом отчёте:** Minecraft 1.21.1 и 1.21.11, Java 21. Для Minecraft 26.x в отчёте указаны отдельные тесты на Java 25. См. [отчёт тестирования](testing.md).

## Возможности

- Создание гильдий, приглашения, заявки и управление составом.
- Передача лидерства и архивирование гильдии с сохранением истории.
- Настраиваемые ранги и права действий внутри гильдии.
- Союзы и войны между гильдиями.
- Дом гильдии, безопасная телепортация и настройки доступа.
- Приватный чат гильдии, объявления и история событий.
- Персональное свечение игроков.
- Захват чанков и защита территории.
- Уровни, улучшение вместимости и PvP-статистика.
- Рейтинги гильдий по PvP и активности.
- PlaceholderAPI, Vault, LuckPerms и Essentials — дополнительные интеграции.
- SQLite, автоматические резервные копии, восстановление и импорт VaelisKRL.

## Установка

1. Убедитесь, что сервер использует подходящую версию Java. Для Minecraft 1.21.x в проверенных сборках использовалась Java 21.
2. Скопируйте `GuildMaster.jar` в папку `plugins/`.
3. Запустите сервер. Плагин создаст папку `plugins/GuildMaster/`, YAML-файлы, SQLite-базу и каталоги резервных копий и логов миграции.
4. При необходимости настройте `config.yml`, `mechanics.yml`, `permissions.yml`, `currencies.yml`, `menus.yml` и `messages.yml`.
5. Для перезагрузки поддерживаемых YAML-настроек используйте `/guildadmin reload`. Изменения корневых команд и алиасов, путей базы и идентификаторов PlaceholderAPI требуют перезапуска.

## Быстрый старт

- `/guild` — открыть главное меню.
- `/guild help` — список игровых команд.
- `/guild create MyGuild` — начать создание гильдии с выбранной валютой/вариантом оплаты.
- `/guild list` — каталог гильдий.
- `/guildadmin help` — справка для администраторов.

Подробные команды и разрешения: [commands.md](commands.md).

## Сборка из исходников

Требуются JDK 21 или 25 и Maven:

```bash
mvn clean verify
```

Готовый JAR появится в `target/GuildMaster.jar`.

## Интеграции

Vault, PlaceholderAPI, LuckPerms и Essentials являются необязательными. Их включение настраивается в `integrations.yml`. Для работы PlaceholderAPI также должен быть установлен сам PlaceholderAPI.

## Данные и безопасность

Данные хранятся в SQLite. По умолчанию база находится в `plugins/GuildMaster/data/guildmaster.db`, резервные копии — в `plugins/GuildMaster/data/backups/`. Платные варианты создания гильдий используют журнал платежей и требуют подтверждения результата платёжного провайдера. Не очищайте базу и не восстанавливайте старую копию без резервного плана.
