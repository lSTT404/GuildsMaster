# Changelog

## 1.0.0

- Introduced the standalone GuildMaster plugin and Black & Gold inventory menus.
- Added configurable ranks, mechanics, translations, currencies, home teleportation and guild administration.
- Added PvP and activity rankings, PlaceholderAPI support and optional Vault and LuckPerms integration.
- Added SQLite schema upgrades, backups, restore staging and a repeatable VaelisKRL importer.
